# Shapez Mods
A collection of my mods for Shapez 2.

All of the mods in this repository are open source and free to use. Most of them are available on the steam workshop, with the only exception being RenderMyFluidPackageSignals.
## Building
If you wish to build any mods yourself, there is a tutorial to do so on the [Shapez 2 Modding Wiki](https://shapez2.wiki.gg/wiki/Mod_Development).

Every mod is a single class library, so nothing too complicated. I may provide builds in this repository in the future, but for now it's much easier to just upload to the steam workshop.
